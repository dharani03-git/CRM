# Kottravai CRM

B2B CRM for sustainable corporate gifting — leads, follow-ups, quotations, and employee sales performance.

## Development

To run the project locally, ensure you have [Bun](https://bun.sh) installed.

```sh
bun install
bun run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
